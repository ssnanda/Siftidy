# Siftidy roadmap — October 2026

**Principles:** personal-use hobby, privacy-first, manual review before destructive actions; iOS/macOS feature parity from the outset. Never auto-delete based on imperfect detection.

| Version | Planned scope | State |
| --- | --- | --- |
| **v0.1** | Shared Flutter iPhone/Mac browser, Photos authorization, paginated thumbnails, selection, review/deletion, basic filters, size estimate, progress | Source foundation completed; Apple build/device QA outstanding |
| **v0.2** | Exact duplicates, visual near-duplicates, no-people-detected review, blur/quality flags, find similar when deleting | Planned |
| **v0.3** | File-size/date/person filters and combinations, presets, protect favorites, regular Mac folder scanning | Planned |
| **v0.4** | Verified local/NAS/Ubuntu archive and restore, resume, integrity checks | Planned |
| **v0.5** | Personal/Work/Reference/Junk collections and searchable archives | Planned |
| **v0.6** | Guided Messages and WhatsApp media cleanup, strictly within Apple sandbox restrictions | Planned |
| **v0.7** | OCR visual search, reminders, archive search, backup integrity checks | Planned |
| **v1.0** | Stable and secure release | Planned |

A full-device iPhone backup and direct third-party access to Messages/WhatsApp are not promised, because iOS app sandbox restrictions prohibit generic access.

# Siftidy roadmap — macOS-first (October 2026)

Siftidy is now **macOS-only**; all further iOS maintenance and iPhone builds are discontinued.

| Version | Scope |
| --- | --- |
| v0.1.x | Apple Photos browsing; Screenshots smart album default, sidebar Albums/Favorites/Photos/Videos, 25-item paging, single-click multi-selection, PhotoKit-managed deletion (no additional in-app confirmation), ZIP-only universal Mac Releases, quick in-place updates, keyboard photo selection, scoped Keepers action, logo and native macOS icons |
| v0.2 | Exact duplicates, visual near-duplicates, screenshot/people/blur suggestions without automatic deletion; menu-bar background scan with Minimal/Eco/Balanced/Turbo profiles, progress/CPU/RAM and optional idle Turbo |
| v0.3 | Date, size, album and no-people combinations; protected favorites; scanning normal Mac folders |
| v0.4 | Verified backup/archive and restore to local disks, NAS or Ubuntu storage |
| v0.5 | Personal/Work/Reference/Junk organization and searchable archives |
| v0.6 | Library categorization and performance refinements on large Mac Photos libraries |
| v0.7 | OCR search, reminders and archive integrity checks |
| v1.0 | Stable, safe, signed/notarized macOS release |

Privacy-first. Deletion requires explicit review and confirmation. iOS is not being developed or distributed.
